# BI-панель руководителя по данным Битрикс24

Веб-приложение на русском языке для презентационной аналитики по проектам, задачам, сотрудникам, рабочему времени и финансам. Backend хранит ключ VibeCode только в переменных окружения и проксирует запросы к `https://vibecode.bitrix24.tech/v1`.

## Возможности

- Главный KPI-дашборд, кликабельные карточки и drill-down.
- Разделы: занятость по проектам, рабочее время, проекты, финансы, задачи, сотрудники, настройки, синхронизация.
- Интерактивные фильтры по периоду, проекту, сотруднику, отделу и статусам.
- Графики Recharts: bar, stacked bar, donut, line, финансовая динамика, heatmap-матрица, Gantt-представление.
- Таблицы с поиском, сортировкой, пагинацией и экспортом CSV.
- Синхронизация с VibeCode/Bitrix24 через backend, кэширование и понятные статусы.
- Fallback на демонстрационные данные, если API или отдельные сущности недоступны.
- Настройка маппинга финансовых полей: сделка CRM, пользовательские поля или смарт-процесс.

## Запуск локально

```bash
npm install
$env:VIBE_API_KEY="vibe_api_..."
npm run build
npm start
```

Приложение откроется на `http://localhost:3000`.

## Переменные окружения

- `VIBE_API_KEY` - ключ VibeCode. Не передавать во frontend.
- `VIBE_API_BASE` - базовый URL API, по умолчанию `https://vibecode.bitrix24.tech/v1`.
- `CACHE_TTL_MS` - TTL кэша аналитики, по умолчанию 5 минут.
- `PORT` - порт сервера, для VibeCode должен быть `3000`.

## Деплой на VibeCode

Deploy API ожидает Node runtime и порт 3000:

```json
{
  "runtime": "node20",
  "install": "cd /opt/app && npm install && npm run build",
  "start": "cd /opt/app && npm start",
  "port": 3000,
  "env": {
    "NODE_ENV": "production",
    "VIBE_API_KEY": "vibe_api_..."
  }
}
```

Ключ маскируется в интерфейсе и логах.
